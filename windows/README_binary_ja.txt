Rogue 5.2 JEC (@DISTNAME@)  Windows版
======================================

Rogueは1980年頃に誕生した、文字や記号で描かれる迷宮を探索する
コンピューターRPGです。プレイヤーは怪物と戦い、さまざまな道具を
使いながら、迷宮の奥に隠された「イェンダーの魔除け」を探します。

Rogueは、現在「ローグライク」と呼ばれるゲームの元祖としても
知られています。プレイするたびに形を変える迷宮、正体や効果を
探りながら使う道具、一度の判断が冒険の行方を左右する緊張感など、
今でも楽しめる特徴を数多く備えています。

このパッケージは、Windows 10 / 11（64ビット）向けの
Rogue 5.2 JEC（@DISTNAME@）です。Rogue 5.2のゲーム内容を基本的に
維持しながら、日本語・英語の切り替え、日本語や絵文字の入力、
カラー表示、現代の端末への対応などを追加しています。

【同梱ファイル】

  @PROGRAM@.exe                 通常版
  @ORIGINAL_PROGRAM@.exe        オリジナル設定版
  rogue_ja.txt                「運命の洞窟への案内書」（日本語）
  rogue_en.txt                「A Guide to the Dungeons of Doom」（英語）
  LICENSE.TXT                 著作権・ライセンス
  README_ja.txt               このファイル
  README_en.txt               英語のREADME

通常版とオリジナル設定版は同じゲーム内容ですが、起動時の
言語・カラー・通路の自動移動・未識別品の呼び名確認・カーソル表示の設定が異なります。
どちらの実行ファイルからでも、ゲーム中に日本語と英語を切り替えられます。

  項目　　　　　　　　　　　　通常版　　　　　　オリジナル設定版
  ------------------------------------------------------------------
  初期表示言語　　　　　　　　OSの設定で選択　　英語
  カラー表示　　　　　　　　　有効　　　　　　　無効
  通路の角で自動移動　　　　　有効　　　　　　　無効
  未識別の品物について尋ねる　有効　　　　　　　無効
  カーソル表示　　　　　　　　無効　　　　　　　有効

言語・カラー・通路の自動移動・未識別品の呼び名確認・カーソルなどは、ゲーム中の
オプション画面でも変更できます。両方の実行ファイルでセーブ・スコアを共用します。

【起動方法】

1. ZIPファイルを任意のフォルダーに展開してください。
   セーブファイルを保存できる、書き込み可能な場所を推奨します。
   （例：C:\Games\Rogue）

2. エクスプローラーから起動する場合は、通常版なら
   @PROGRAM@.exe、オリジナル設定版なら
   @ORIGINAL_PROGRAM@.exeをダブルクリックします。

   既定のセーブファイルがある場合は、次のメニューが表示されます。

     [R/Enter] セーブした冒険を再開する
     [N]       新しい冒険を始める
     [F]       別のセーブファイルを選ぶ
     [Q]       終了する

   セーブファイルがなければ、メニューなしで新しいゲームが始まります。
   [F]ではWindowsのファイル選択画面が開き、キャンセルすると
   メニューに戻ります。新しい冒険を始めても、既存のセーブファイルは
   その時点では削除されません。

3. セーブファイルを @PROGRAM@.exe または
   @ORIGINAL_PROGRAM@.exe にドラッグ＆ドロップすると、
   そのファイルから直接再開できます。

4. ターミナルから起動するには、展開先フォルダーを開き、
   Windows 11では右クリックから「ターミナルで開く」を選びます。
   この項目がない場合は、フォルダーのアドレスバーにpowershellと
   入力してEnterを押してください。起動コマンドは次のとおりです。

   通常版：
       .\@PROGRAM@.exe

   オリジナル設定版：
       .\@ORIGINAL_PROGRAM@.exe

   コマンドプロンプト（cmd.exe）からも起動できます。
   既に開いているターミナルから引数なしで起動した場合は、
   新しいゲームが始まります。

端末は80列×24行以上でご利用ください。ゲームの描画範囲は80×24に
固定されています。ダブルクリック起動時には、Windows Terminalや
Console Hostのウィンドウを80×24に調整する処理が働きますが、
環境によっては調整されない場合もあります。既に開いている
ターミナルから起動した場合は、ウィンドウサイズを変更しません。

ゲーム中に「!」を入力するとシェルへ移動できます。「exit」で
シェルを終了するとゲームに戻ります。

【セーブデータとスコア】

ゲーム中の「S」コマンドで冒険を保存できます。
ターミナルから既定のセーブファイルを再開する場合：

       .\@PROGRAM@.exe -r

別の名前・場所にあるセーブファイルを再開する場合：

       .\@PROGRAM@.exe "保存ファイル名"

スコア一覧だけを表示する場合：

       .\@PROGRAM@.exe -s

オリジナル設定版では、上記の@PROGRAM@.exeを
@ORIGINAL_PROGRAM@.exeに置き換えてください。
正常にゲームを再開すると、元のセーブファイルは削除される仕様です。
残しておきたいセーブデータは、再開前にコピーしてください。

通常版とオリジナル設定版で共通の既定ファイル名は次のとおりです。

  セーブファイル         @PROGRAM@.save
  スコアファイル         @PROGRAM@.scr

これらは起動時の作業フォルダーを基準に作成・参照されます。
エクスプローラーから直接起動した場合は、通常は実行ファイルの
あるフォルダーです。両方の実行ファイルから同じ冒険を再開でき、
スコアも共通です。ただし、同じセーブファイルを複数のゲームで
同時に使用することは避けてください。

ゲーム終了後、ダブルクリック起動時はスコア画面を表示したまま
リターンキーの入力を待ちます。既に開いているターミナルから
起動した場合は、この終了待ちを追加しません。

ROGUEOPTSのfile=で、既定のセーブファイル名を変更できます。

【Windowsでの環境変数の設定】

起動時の設定には環境変数ROGUEOPTSを使用できます。
設定項目の意味は、同梱の案内書の「オプション」をご覧ください。
ここではWindowsで設定する方法だけを説明します。

PowerShellで一時的に設定する例：

       $env:ROGUEOPTS = "name=勇者,language=ja"
       .\@PROGRAM@.exe

コマンドプロンプト（cmd.exe）での例：

       set "ROGUEOPTS=name=勇者,language=ja"
       @PROGRAM@.exe

これらの指定は、その端末とそこから起動したプログラムに有効です。
エクスプローラーからのダブルクリックには引き継がれません。

常に同じ設定で遊びたい場合は、Windowsのユーザー環境変数に登録します。

  1. Win + Rで「ファイル名を指定して実行」を開き、sysdm.cplを実行。
  2. 「詳細設定」→「環境変数」を開く。
  3. 「ユーザー環境変数」で「新規」を選ぶ（既存なら「編集」）。
  4. 変数名にROGUEOPTS、変数値に設定文字列を入力する。
  5. 「OK」で保存する。必要ならWindowsへ再サインインする。

設定をやめるときは、登録したユーザー環境変数を削除してください。

【遊び方とライセンス】
